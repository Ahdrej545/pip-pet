# Пип для Windows и Android 🦊

Отдельный питомец для экрана. Работает без ChatGPT и интернета.

## Новое в 1.1

- Запоминает место, размер, скорость и активность после перезапуска.
- Без внимания засыпает через полторы минуты. Поглаживание будит Пипа и радует его.
- Умеет сидеть, отдыхать и играть: команда «Поиграть» запускает короткую серию прыжков, приветствий и пробежек.
- Есть спокойный, обычный и игривый режимы, а также три скорости.
- Режим «не мешать» временно прячет питомца. Windows: 15, 30 или 60 минут; Android: 30 минут. Показать снова можно раньше срока.
- На Windows автоматически прячется в полноэкранных приложениях. Эту настройку можно отключить.
- Кнопка «Проверить обновления» сверяет версию с GitHub. При наличии новой версии предлагает открыть страницу скачивания; сама ничего не устанавливает.

Интернет используется только по нажатию проверки обновлений. Основные функции остаются доступными без сети. Новые состояния используют готовые позы из оригинального спрайта.

## Windows

Запусти `Pip.exe`. Нужен Windows с .NET Framework 4.x; сборка проверена на компьютере автора.

Для установки с ярлыком и автозапуском скачай эту папку и запусти `Install-Windows.ps1`. Он копирует приложение в `%LOCALAPPDATA%\PipDesktop`, создаёт ярлык «Пип» на рабочем столе и включает запуск после входа в Windows. Права администратора не требуются.

Перетаскивай Пипа мышью. Один клик — приветствие, двойной — прыжок. Чтобы погладить, проведи курсором по лисёнку туда-сюда без зажатой кнопки. Правый клик по Пипу или значку в трее открывает меню настроек, сна, игр и обновлений. Двойной клик по значку в трее отменяет ручной режим тишины.

## Android

Установи `Pip.apk`, открой приложение «Пип» и нажми «Показать Пипа». Разреши отображение поверх других приложений и уведомления.

Перетаскивай лисёнка пальцем. Один тап — приветствие, два — прыжок. Короткие движения туда-сюда по Пипу — поглаживание. Можно также нажать «Погладить» в приложении. Долгое нажатие открывает управление. Остановить Пипа можно в приложении или из уведомления; при выключенном экране анимация останавливается. Кнопка «Показать Пипа» отменяет режим тишины.

В приложении есть изменение размера и переключатель запуска после включения телефона. Некоторые производители дополнительно ограничивают автозапуск и фоновую работу.

## Исходники и сборка

- `windows/Pip.cs` — приложение Windows.
- `android/src/` — приложение Android.
- `android/AndroidManifest.xml` — разрешения и компоненты Android.
- `build.py` — сборка.

Для Windows нужен компилятор C# из .NET Framework. Для Android — JDK 17, Android SDK Platform 34 и Build Tools 36.0.0. Python 3 нужен для скрипта сборки; сторонние Python-пакеты не требуются. Пути можно задать через `JAVA_HOME` и `ANDROID_HOME`.

```text
python build.py --windows-only
python build.py --android-only
```

Скрипт сохраняет промежуточные файлы и локальный ключ подписи в `.build/`, которая исключена из Git. Другую папку можно задать через `PIP_BUILD_DIR`. Для обновления существующей Android-установки нужен тот же ключ, которым она подписана. Сохрани свой ключ и файл пароля; не публикуй их.

Официальный APK в этой папке подписан ключом проекта. Приватный ключ в репозиторий не включён. Разрешение на интернет нужно для ручной проверки версии. Доступ к контактам, сообщениям, камере или микрофону не запрашивается.

## Проверено

На Windows проверены запуск, прозрачное окно, ярлык и настройка автозапуска. Автоматические проверки покрывают сохранение настроек, порог сна, реакцию на поглаживание, сравнение версий и полноэкранную геометрию. На Android проверены сон, пробуждение и радость от кнопки и жеста поглаживания, игры, режим тишины, изменение параметров и восстановление места и настроек после перезапуска службы. Запуск после полной перезагрузки устройств пока не проверен.
