# Пип для Windows и Android 🦊

Отдельный питомец для экрана. Работает без ChatGPT и интернета.

## Скачать

- [Pip.exe — Windows](https://github.com/Ahdrej545/pip-pet/raw/refs/heads/main/standalone/Pip.exe)
- [Pip.apk — Android 11 и новее](https://github.com/Ahdrej545/pip-pet/raw/refs/heads/main/standalone/Pip.apk)

## Windows

Запусти `Pip.exe`. Нужен Windows с .NET Framework 4.x; сборка проверена на компьютере автора.

Для установки с ярлыком и автозапуском скачай эту папку и запусти `Install-Windows.ps1`. Он копирует приложение в `%LOCALAPPDATA%\PipDesktop`, создаёт ярлык «Пип» на рабочем столе и включает запуск после входа в Windows. Права администратора не требуются.

Перетаскивай Пипа мышью. Один клик — приветствие, двойной — прыжок. Правый клик по Пипу или значку в трее открывает меню: пауза, размер, поверх окон, автозапуск и выход.

## Android

Установи `Pip.apk`, открой приложение «Пип» и нажми «Показать Пипа». Разреши отображение поверх других приложений и уведомления.

Перетаскивай лисёнка пальцем. Один тап — приветствие, два — прыжок. Долгое нажатие открывает управление. Остановить Пипа можно в приложении или из уведомления; при выключенном экране анимация останавливается.

В приложении есть изменение размера и переключатель запуска после включения телефона. Некоторые производители дополнительно ограничивают автозапуск и фоновую работу.

## Исходники и сборка

- `windows/Pip.cs` — приложение Windows.
- `android/src/` — приложение Android.
- `android/AndroidManifest.xml` — разрешения и компоненты Android.
- `build.py` — сборка.

Для Windows нужен компилятор C# из .NET Framework. Для Android — JDK 17, Android SDK Platform 34 и Build Tools 36.0.0. Python 3 нужен для скрипта сборки; сторонние Python-пакеты не требуются. Пути можно задать через `JAVA_HOME` и `ANDROID_HOME`.

```text
python build.py --windows-only
python build.py --android-only
```

Скрипт сохраняет промежуточные файлы и локальный ключ подписи в `.build/`, которая исключена из Git. Для обновления существующей Android-установки нужен тот же ключ, которым она подписана. Сохрани свой ключ и файл пароля; не публикуй их.

Официальный APK в этой папке подписан ключом проекта. Приватный ключ в репозиторий не включён. Доступа к сети, контактам, сообщениям, камере или микрофону приложение не запрашивает.

## Проверено

На Windows проверены запуск, прозрачное окно, ярлык и настройка автозапуска. На Android проверены отображение поверх приложения, перетаскивание, изменение размера, остановка и повторный запуск. Запуск после полной перезагрузки устройств пока не проверен.

Графика создана с помощью imagegen. Приложения используют готовые рисунки Пипа.
